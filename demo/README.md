# Demo Materials

Sample data and resources for AMS demonstrations and testing.
None of these files are loaded by application code — they are for manual upload testing only.

## Folders

### `summit-import/`
J-series CSV files in DataPath Summit format for testing the **Summit Import Wizard** (`SummitImportWizard.java`).
Two employers (Meridian Group, Riverstone) with 9 employees and CDH/COBRA benefits.

### `interactive-import/`
Generic-format CSV files for testing the **Interactive Import Wizard** (`InteractiveImport.java`).
10 Michigan employers with 25 employees and 27 benefit enrollments across multiple plan types.

### `brochures/`
Sample brochure content (HTML source + rendered PDF) for COBRA, FSA, and portal login instructions.
Uses SSA brand colors (#0d5681, #87a948) and DM Sans font.
