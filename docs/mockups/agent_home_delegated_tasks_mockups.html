AgentHome Delegated Tasks — 3 Alternatives

Same user (Zoe Lam, Lam Benefits Group) with 5 delegated ToDos across 3 Setups. Each mockup shows how the AgentHome page would frame them against the existing opportunity pipeline.

A  ·  Priority Inbox strip above the pipeline

Flat list · inline complete
Idea: single scannable strip at the top of the page. Every open task the agent owns is a row with a one-click Complete button and a click-through to the Setup. Sorted by due date; overdue floated to the top. Filter toggles by Setup so a busy agent can narrow down. Keeps the Kanban as the focal point below.
Best when: task count is low-to-medium (≤20) and most work is quick.

B  ·  Persistent sidebar (right column)

Always visible · grouped by Setup
Idea: the Kanban keeps the majority of the page but a 300px right column anchors the agent's open tasks grouped by Setup. Sticky while the Kanban scrolls horizontally. Grouping keeps context tight ("all of my Acme tasks together") — good when an agent typically works one Setup at a time.
Best when: an agent works deeply on a single Setup and moves between several of them deliberately.

C  ·  Smart attention banner + task drawer

Minimal by default · expands on demand
Idea: keep the AgentHome visually dominated by the pipeline. A thin yellow banner at the top calls out action-required counts (overdue, due-soon, queued). Clicking opens a drawer with a tabbed task list — Needs Action, Waiting on PSP, Recently completed — so the agent can clear their plate without losing sales context. When zero open tasks, the banner becomes a discreet green "All caught up" pill instead.
Best when: agents spend most of their time in the Kanban and occasionally need to knock out setup homework.

Quick comparison
  A — Priority Inbox Strip B — Sidebar Tasks C — Attention Banner + Drawer
Glance time Fast — all tasks visible immediately Fast — sidebar is permanent Very fast — one-line summary
Screen weight Medium — strip can get tall Heavy — sidebar always takes ~320px Light — just a banner until opened
Action density High — every row actionable inline High — grouping by Setup aids focus Medium — one extra click to open drawer
Handles high task count Needs filters and scrolling Scrolls cleanly inside sidebar Best — drawer only appears when needed
Gets out of your way Low — always visible Low — always visible High — dismiss/collapse
Best fit Task-forward agents who live in the task list Agents who treat tasks as an ever-present co-pilot Sales-forward agents who tolerate setup homework as it arises
