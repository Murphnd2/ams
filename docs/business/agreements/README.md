# SSA Service Agreement Set — Draft v1 (2026-09-14)

This directory holds draft v1 of Superior State Administrators' modular service agreement set, produced in the 2026-09-14 side session: a Master Services Agreement, a Business Associate Agreement, ten service Appendices/Riders, two Schedules, the review that motivated the rewrite, and the open items register. None of these documents is finalized, none has been reviewed by Employer's or SSA's counsel, and none has been issued to a client. Document activity on this set is parked.

**These are drafts carrying open items — start with the register, not the documents.** Every document below carries bracketed `[ ]` decision points and ⚠️-flagged issues in its own text. `open_items_register_v1.md` is the authoritative index into all of them, organized by category (decisions for Kevin, verification items, drafting risks, etc.) with severity and blocking/non-blocking status. A future session should read the register first to find out what's unresolved before opening any individual document.

## How the set fits together

- **MSA-2026** and **BAA-2026** are signed once, at onboarding, and govern the whole relationship.
- Each service Appendix (APX-RA, APX-POP, APX-TRANSIT, APX-COBRA, APX-PAYMENT, APX-CARD) is elected individually in **MSA Article VII** — Employer only signs on to the services it actually buys.
- **RIDER-ICHRA** and **RIDER-QSEHRA** supplement **APX-RA** and apply only when the corresponding HRA type is elected; they do not stand alone and do not apply to each other's arrangement.
- **SCH-BANKING** and **SCH-CONTACT** are schedules — they can be replaced by Employer at any time with a new executed schedule, without amending the Agreement itself.
- **SCH-FEE** (the fee schedule) is the proposal by number and is **not drafted** — it isn't in this directory because it doesn't exist as a standalone document yet.
